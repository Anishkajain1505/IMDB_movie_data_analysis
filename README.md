# IMDb Movie Data Analysis

## Project Overview
This project explores IMDb movie data using Python to identify trends in movie ratings, genres, revenue, popularity, and other movie-related attributes through Exploratory Data Analysis (EDA).

## Objectives
- Analyze movie ratings and genre distributions.
- Explore relationships between ratings, revenue, and popularity.
- Identify trends and patterns in movie data.
- Create visualizations to communicate insights effectively.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Files
- `IMDb_Movie_Analysis.ipynb` — Jupyter Notebook containing data cleaning, analysis, and visualizations.
- `imdb_movies.csv` — Dataset used for the analysis.

## Key Analysis
- Data exploration and cleaning
- Summary statistics
- Genre and rating analysis
- Revenue and popularity analysis, where available
- Correlation analysis and data visualization

## How to Run
1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

3. Open the notebook in Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

4. Run the notebook cells in order.

## Conclusion
This project demonstrates the use of Python-based data analysis and visualization techniques to explore movie industry data and uncover meaningful patterns.
